# Documentation history

The active documentation describes only the Teams app, its API boundary, its
Microsoft technology choices, its deployment, and its safety rules.

Superseded web/admin architecture, TypeScript runtime guides, UI proposals,
alternate deployment plans, tenant handoff notes, and detailed domain plans
were removed from this branch because they are not current instructions. Their
last committed copies remain available through Git history, including the
pre-cleanup checkpoint. Numbered files in `specs/` and `results/` are retained
as the authoritative historical execution record and are not rewritten.
